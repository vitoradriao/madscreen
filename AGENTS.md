# Trabalhar no madscreen

Leia [CONTRIBUTING.md](CONTRIBUTING.md) e execute os testes do componente alterado.
Envie contribuições por pull request neste repositório. O mantenedor incorpora cada
mudança aceita à árvore de desenvolvimento antes da próxima sincronização pública.
Preserve o histórico, os autores e as tags já publicadas.

As releases do app usam a tag `vX.Y.Z` do código correspondente. Consulte as
[releases oficiais](https://github.com/vitoradriao/madscreen/releases) para obter
o instalador, as assinaturas e as fontes. O canal antigo atende instalações até a 0.1.25.
