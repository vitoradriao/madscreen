# ScreenDialogs

Prancha com os diálogos de servidor e canal no estilo novo: cada um com título, um campo ou a consequência, Cancelar e a ação nomeada.

- O botão de confirmação repete o verbo do título ("Apagar servidor", não "Confirmar"). Destrutivos usam `.btn.danger`.
- Entrar por convite mostra o servidor de destino (nome, quem convidou, membros) antes de entrar.
- Convidar mostra o link em mono com Copiar ao lado.
- Sair do servidor muda o texto conforme o papel: para o dono, "Outro membro assumirá como dono…"; para os demais, "Você precisará de um novo convite para voltar."
