# ScreenMenus

Os três menus de gerenciamento, com o gatilho de cada um: nome do servidor no cabeçalho, engrenagem nas abas de canal e ⋯ na linha do membro.

- As opções dependem do papel; esconda o que a pessoa não pode fazer em vez de desabilitar.
- A ação destrutiva vem por último, depois de um separador, sublinhada, e sempre abre um diálogo.
