# ScreenDirectoryError

Falha ao carregar o diretório: faixa de erro (borda inferior de 2px em `text`, ícone de alerta e Tentar de novo) sobre a estrutura em esqueleto.

- O esqueleto é estático: blocos `surface-2` no lugar das miniaturas e dos membros, sem animação.
- O mesmo esqueleto, sem a faixa, é o estado "carregando" da primeira abertura.
