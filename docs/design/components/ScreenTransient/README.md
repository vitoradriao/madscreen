# ScreenTransient

Prancha dos estados de passagem que não têm captura: carregando, iniciando, parando, som bloqueado, fonte fechada e atualização com falha.

- Carregando: esqueleto estático. Iniciando e Parando: badge contornado com a frase do que está acontecendo; Iniciando oferece Cancelar, Parando desabilita Parar.
- Som bloqueado: aviso no centro do vídeo com Ativar som (o navegador do app exige um clique antes de tocar áudio).
- Fonte fechada: erro com Trocar janela ou tela e Parar. Este design não define o que acontece com a live; segue o comportamento atual do app.
