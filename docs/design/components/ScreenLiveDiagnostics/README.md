# ScreenLiveDiagnostics

Detalhes e diagnóstico da sua live: painel de 320px no lugar dos membros, com FPS e envio contra o alvo, codificador ativo, fonte, som, conexão e espectadores.

- Números grandes (`target`) mostram o valor e o alvo logo abaixo. Copiar diagnóstico da transmissão é a ação principal.
- Mesmo padrão do painel de ajuda de quem assiste (ScreenWatchHelp).
