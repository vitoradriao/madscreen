# ScreenWatchHelp

Detalhes e ajuda do player: painel de 320px à direita, no lugar do painel de membros, com números, observações e Copiar diagnóstico.

- Números em mono (resolução, quadros, taxa, ida e volta). Cada observação tem estado em palavra: NORMAL (ponto cheio) ou PARADA (quadrado vazado), nunca só cor.
- As observações são um retrato do último intervalo; Atualizar observações tira outro. Copiar diagnóstico é a ação principal.
- Explica que os dados do computador de quem transmite não aparecem aqui e pede o diagnóstico da transmissão à outra pessoa.
