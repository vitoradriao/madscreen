# ScreenAccountAdmin

Serviço de transmissão, só para contas autorizadas: provedor das novas transmissões, uso estimado, sondas de controle e a escolha do provedor.

- O provedor atual vem destacado com Verificar serviços ao lado. O uso aparece como barra (`accent` sobre `surface-4`) com a nota de incerteza.
- Cada sonda tem estado em palavra: SAUDÁVEL (ponto cheio), SEM DADO (anel vazado). Fica escrito que medem o controle, não o vídeo.
- Provedor: Automático, Forçar Cloudflare, Forçar LiveKit, como QualityOptions; vale só para transmissões novas.
