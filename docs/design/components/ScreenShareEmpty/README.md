# ScreenShareEmpty

Minha transmissão antes de escolher a fonte: três passos numerados (Canal, Fonte e som, Qualidade e FPS), com a qualidade travada até haver fonte.

- O passo concluído ganha o número em `accent`. Compartilhar fica desabilitado com a nota "Escolha uma fonte para continuar".
- "Nunca o microfone" fica explícito no passo de fonte: o app só compartilha som de aplicativos ou do PC.
