# ScreenReconnecting

Diretório desconectado: uma faixa abaixo do cabeçalho avisa e tenta reconectar sozinha; o resto da tela continua utilizável.

- A faixa usa `surface-2` com ícone de atualizar, frase e Tentar agora. Some sozinha quando a conexão volta.
- A presença no painel de membros fica esmaecida, com a nota "Presença desatualizada"; as miniaturas continuam, porque as lives abertas não dependem do diretório.
