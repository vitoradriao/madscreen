# ScreenWatchOne

Assistindo uma live: o vídeo ocupa a área toda; o painel de membros recolhe para dar espaço e volta pelo botão de pessoas.

- Barra superior sobre o vídeo: nome, AO VIVO, fonte e qualidade, espectadores. Barra inferior: som (M) e volume, números da transmissão em mono, Ajuda, mini-player e tela cheia (F). As duas somem após alguns segundos sem mouse e voltam com hover ou foco.
- Acima do vídeo: quantas lives estão abertas (até 2), Adicionar transmissão e Sair da transmissão.
- Sem faixa de áudio: a barra inferior troca o volume pelo texto "Sem som nesta transmissão" (ver ScreenWatchTwo).
