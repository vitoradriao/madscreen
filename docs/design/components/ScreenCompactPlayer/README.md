# ScreenCompactPlayer

Player compacto dentro do app: ao sair da vista Assistir com uma live aberta, ela continua num cartão de 340px no canto inferior direito do conteúdo.

- Cabeçalho: AO VIVO, nome, fonte, Voltar ao player e Fechar. Sobre o vídeo: som, volume e mini-player.
- Fica acima do conteúdo (`shadow-floating`), nunca sobre o painel de membros. O aviso de atualização, se aparecer, sobe acima dele.
- Não é o mini-player: este vive dentro da janela principal.
