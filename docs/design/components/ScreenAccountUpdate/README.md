# ScreenAccountUpdate

Atualizações em Conta com versão nova: o cartão da versão ganha contorno duplo `accent` e Instalar e reiniciar.

- Sem versão nova, o mesmo cartão diz "Você está na versão mais recente", quando foi verificado e oferece Verificar agora.
- A mesma verificação alimenta o aviso flutuante; a Conta não faz consulta própria.
