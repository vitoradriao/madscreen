# ScreenChannel

Canal com duas lives: ServerRail, Topbar com abas, StreamTile, ShareCallout, MemberList e o UpdateNotice no canto.

- Três colunas: `rail-w` · conteúdo · `members-w`. O painel de membros recolhe pelo botão de pessoas do cabeçalho, e as miniaturas ocupam a largura.
- Uma ação primária no cabeçalho (Compartilhar tela) e uma por live ao vivo (Assistir).
- O aviso de atualização fica no canto inferior direito do conteúdo, sem cobrir o painel de membros.
