# ScreenAccount

Conta e preferências: navegação de seções à esquerda e uma seção por cartão, com interruptores para o que liga e desliga.

- Aberta pelo seu avatar no rodapé da barra de servidores (fica contornado enquanto a Conta está aberta). "Voltar para # Geral" no cabeçalho.
- Seções: Conta (identidade, servidor do app, versão, Sair da conta), Aparência, Avisos, Reprodução de vídeo, Atualizações e, só para administradores do serviço, Serviço de transmissão.
- Aparência (tema Grafite / Papel / Alto contraste) é uma adição deste design: o app atual não tem escolha de tema.
