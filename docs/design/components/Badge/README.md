# Badge

Etiquetas de estado; AO VIVO é a única preenchida.

- `.badge.live` (fundo `accent`, ponto pulsante). `.badge` contornado para estados (Pausado, Iniciando, Reconectando). `.badge.over` e `.pill` (espectadores) sobre vídeo, com fundo `overlay`.
- `.role` para papéis ao lado do nome (DONO, ADMIN). `.count` para a contagem de lives na aba do canal.
