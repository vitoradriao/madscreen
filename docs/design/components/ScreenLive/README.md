# ScreenLive

Minha transmissão ao vivo: a prévia muda no palco, controles independentes de vídeo e som, qualidade ao lado e os membros à direita.

- O cabeçalho troca Compartilhar tela por Minha transmissão (contornado) enquanto você está ao vivo.
- Parar é a única ação destrutiva (`.btn.danger`). Pausar vídeo e Silenciar áudio compartilhado são independentes.
