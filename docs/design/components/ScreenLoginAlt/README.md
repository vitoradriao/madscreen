# ScreenLoginAlt

Entrar sem Discord, criando conta: Segmented "Tenho um convite / Já tenho conta"; com convite, o servidor de destino aparece antes do nome de usuário e de Criar conta.

- Com o acesso alternativo aberto, Criar conta é a ação principal e Continuar com Discord desce para botão contornado, depois de um separador "ou".
- O cartão do servidor aparece quando o convite é conferido (o app já confere o convite colado). Conferir se o canal de destino também vem nessa resposta.
