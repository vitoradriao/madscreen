# ScreenMiniPlayer

Mini-player em janela separada (640×360, sem moldura nativa), sempre no topo quando fixado.

- Com hover ou foco: barra superior arrastável com nome, AO VIVO, Fixar/Fixado (alterna, `accent` quando ligado), Controles e Voltar (volta à janela principal sem fechar a live). Barra inferior com som e volume.
- Sem mouse: só o vídeo. O som continua tocando.
- Posição e tamanho são da janela do Windows (Tauri); o design não desenha moldura própria.
