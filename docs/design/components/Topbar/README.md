# Topbar

Cabeçalho de 64px: servidor com menu, canais como abas e as ações à direita, com a primária por último.

- A aba atual tem sublinhado de 2px `accent` e o `.count` de lives. A engrenagem é Opções do canal.
- O botão de pessoas (`aria-pressed`) abre e fecha o painel de membros.
- Substitui a barra de canais da versão anterior: canais e ações do servidor ficam todos aqui.
