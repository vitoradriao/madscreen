# ScreenWatchTwo

Duas lives: destaque 7fr/3fr (ou Lado a lado), com uma tela selecionada que recebe a próxima transmissão.

- Barra: Segmented Destaque / Lado a lado (substitui "Telas iguais"), Trocar destaque (D), Som só no destaque, Adicionar transmissão.
- Cada tela tem rótulo (TELA 1 · DESTAQUE), nome, AO VIVO, som próprio e Sair. A selecionada recebe contorno `accent` de 2px.
- Live sem áudio: sem botão de som, e a legenda termina em "sem som nesta transmissão".
- O aviso explica qual tela será substituída; nada muda sem o clique.
