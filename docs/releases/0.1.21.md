# madscreen 0.1.21

- **Login com Discord no app:** o navegador volta a abrir ao escolher Continuar com Discord. Na 0.1.20 o endereço do Hub novo não estava liberado para abrir no navegador do sistema, e a tela ficava esperando sem abrir nada.
