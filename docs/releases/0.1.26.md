# madscreen 0.1.26

O instalador, as atualizações assinadas e o código-fonte agora ficam juntos
nas [releases do projeto](https://github.com/vitoradriao/madscreen/releases).
Quem usa a 0.1.25 ou uma versão anterior com o atualizador assinado pode
instalar a 0.1.26 pelo aviso habitual. A partir dela, o app consulta o novo endereço.
O instalador mantém a chave de atualização e a identidade do aplicativo.
