# madscreen 0.1.3

- Novo botão **Copiar diagnóstico** no player para registrar os últimos segundos
  após uma travadinha, com RTT, perdas, decode e apresentação. Não envia dados
  automaticamente e não inclui credenciais nem conteúdo de vídeo/áudio.
- RTT passa a usar o transporte selecionado do vídeo, evitando mostrar um par
  antigo quando o navegador mantém várias conexões nominadas no relatório.
- Controles se ajustam ao espaço disponível em duas telas e miniatura.

Essa versão melhora a investigação. Não atribui as pausas raras a um valor de
RTT específico nem afirma que a causa foi corrigida. Inclui a correção AMF da
0.1.2, ainda pendente de validação nas duas GPUs AMD relatadas.

Na 0.1.2, consulte **Conta → Verificar atualizações** para receber esta versão
assinada. Quem ainda está na 0.1.1 precisa instalar manualmente uma vez.
